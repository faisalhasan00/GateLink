# 15. Project Glossary & Terminology

- **RWA**: Resident Welfare Association (local management committee of a housing society).
- **Society Code**: 6-character unique identifier assigned to each society (e.g. `SOC-001`).
- **SocietyId**: Database document key identifying a specific tenant housing society.
- **Pending Approval**: Account state of a newly self-registered mobile resident requiring verification by their RWA Admin.
- **FCM**: Firebase Cloud Messaging (push notification system).
- **HomeHni Hood**: Brand name of the SaaS platform.
- **HomeHni Residency**: App title of the Resident mobile app.
- **HomeHni Guard**: App title of the Security Guard mobile app.
